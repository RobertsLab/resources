# [Things yoU Should Know](https://robertslab.github.io/tusk/) (TUSK)

We have a dedicated website to serve as a reference/guide for aspects of the lab you should become familiar with, like:

- [Lab Work](https://robertslab.github.io/tusk/modules/06-lab-work.html): Basic guides for common procedures like washing dishes, DNA/RNA isolation, sample homogenization, etc.

- [markdown](https://robertslab.github.io/tusk/modules/00-markdown.html): Text-based, human-readable text formatting for notebooks and GitHub.

- [GitHub](https://robertslab.github.io/tusk/modules/01-github.html): Collaboration, version control, and sharing for data/projects in the lab.

- [Bash](https://robertslab.github.io/tusk/modules/02-bash.html): Common command-line/terminal commands for file/data exploration and manipulation.

- [R Studio](https://robertslab.github.io/tusk/modules/03-rstudio.html): An interface for using the programming language `R`, as well as programs in a terminal. R Studio also serves as an easy, graphical user interface (GUI) means to interact with various lab/UW computers (Raven, Hyak).

- [NCBI BLAST](https://robertslab.github.io/tusk/modules/04-blast.html): An overview of one of the most common computing tasks performed in the lab: Basic Local Alignment Search Tool (BLAST).
