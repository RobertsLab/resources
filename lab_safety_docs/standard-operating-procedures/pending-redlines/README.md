# Pending redlines

Proposed text changes to a formal SOP (`SOP-01` … `SOP-15`), staged here as
`SOP-NN.md` instead of edited directly into the `.docx`/`.pdf`.

The SOPs are signed, EH&S-template documents — a scripted or automated edit to
the binary file risks corrupting signatures/formatting, so changes are drafted
here first and applied by hand in Word, then re-approved per the "Review
cadence" section of the [SOP README](../README.md).

Files land here automatically via
[`.github/workflows/sop-sync.yml`](../../../.github/workflows/sop-sync.yml),
which opens a GitHub issue (assigned to Copilot) whenever
`docs/Chemical-Standard-Operating-Protocols.md` changes in a way that might
affect one of these SOPs. Once a redline here has been applied to the `.docx`
in Word, delete the corresponding `SOP-NN.md`.
