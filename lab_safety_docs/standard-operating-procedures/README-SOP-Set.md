# Roberts Lab Chemical SOP Set (Rev. 0, September 1, 2026)

Built from the MyChem Campus Inventory Report `CampusInvReport_Chemical_Hazard_20260901184741.csv`
(85 inventory lines, FTR Rooms 209 and 213, PI Steven Roberts).

Format follows the UW EH&S blank chemical SOP template (`blankchemsop.docx`), Sections 1-12.
UW explicitly permits an SOP to cover "a single chemical, a group of similar chemicals, or a process,"
so these are organized by hazard class.

because the underlying practices (authorization, decontamination, work-location discipline)
are worth writing down regardless.

## Basis for each PHS designation

- **Chloroform** - GHS Carcinogenicity Cat 2, Reproductive toxicity Cat 2 (select carcinogen)
- **Formaldehyde 37%** - GHS Carcinogenicity Cat 1A, IARC Group 1; also substance-specific regulated under WAC 296-856
- **TRIzol LS and phenol reagents** - Acute toxicity Cat 3 all routes, Germ cell mutagenicity Cat 2; phenol is a high-acute-toxicity substance
- **Ethidium bromide** - Acute toxicity Cat 2 (inhalation), Germ cell mutagenicity Cat 2
- **Sulfuric acid 90-100%** - GHS Carcinogenicity Cat 1A (strong inorganic acid mist, IARC Group 1)
- **2-Mercaptoethanol** - Acute toxicity Cat 2 dermal and inhalation, Reproductive toxicity Cat 2
- **5-Azacytidine** - cytotoxic antineoplastic; carcinogen / mutagen / reproductive toxicant
- **4-Methoxyphenol, serotonin creatinine sulfate** - Reproductive toxicity Cat 2

## Review cadence

Review annually, and immediately after any incident, near miss, new chemical purchase, or process change.
Training must be repeated after any revision to SOP content.
